# Galactic-War-Guardian-Donor
Add-on for Galactic War Overhaul. With Separate loadouts &amp; tech on, The Guardians copy the tech cards, AI tech and race of ONE randomly chosen player per battle instead of every player's. Changes no GWO file; it patches GWO's referee modules in memory as they load. Might Break on future updates of Galactic War Overhaul.
